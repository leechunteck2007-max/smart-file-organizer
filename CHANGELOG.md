# Changelog

## [0.2.0-alpha]

First public alpha of Smart File Organizer V2.

- Scan Computer → Organize Files → result, with optional detail/history/settings.
- Windows known-folder/local drive discovery; read-only pause/resume/cancel.
- System, application, project, link and offline-file protection; meaningful human folders retained.
- Local rules and bounded document inspection; conservative classification/renaming.
- Same-volume no-overwrite moves, collision suffixes and journaled session Undo.
- Hash-confirmed duplicates/eligible cleanup quarantined under Review Before Delete.
- Automatic local Word reports and complete JSON appendices.
- Standalone Windows x64 build, synthetic integration tests and Windows workflows.
- MIT license and public safety/privacy/contribution/security documentation.

See [Known issues](KNOWN_ISSUES.md). Earlier private labels are not public releases.
