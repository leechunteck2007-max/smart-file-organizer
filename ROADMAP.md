# Roadmap

## 0.2 alpha — implemented

Automatic local discovery, protected read-only scanning, conservative local classification/renaming, automatic organization, SHA-256 duplicate detection, Review Before Delete, journaled Undo and DOCX/JSON reports. React/Electron desktop and standalone Windows x64 package.

## Next iteration

Independent-PC and physical external-drive acceptance, classification feedback, scan performance measurements, clearer recovery/errors and accessibility improvements. Broaden regression fixtures from sanitized feedback.

## Possible future work

Optional classification providers with explicit privacy controls, custom rules, opt-in background organization and additional platforms. Proposals, not implemented features or dated commitments.
