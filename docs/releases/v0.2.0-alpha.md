# Smart File Organizer v0.2.0-alpha

**Two clicks from messy to organized:** Scan Computer → Organize Files → Done.

First alpha: local discovery, pause/cancel scanning, conservative classification/renaming, project/application/system protections, same-volume no-overwrite organization, duplicate/cleanup review, session Undo and automatic Word/JSON reports.

## Install

Download `SmartFileOrganizer-v0.2.0-alpha-Windows-x64.zip`, compare SHA-256 with the accompanying checksum file, extract the whole folder and run `SmartFileOrganizer.exe`. Keep runtime files together. Python/Node are unnecessary; a Word-compatible viewer opens reports. Unsigned: Windows may show unknown-publisher warnings.

## Safety

Back up important files and start in a disposable Windows account/VM with non-critical data. Organize Files authorizes the automatic eligible plan. Cleanup extras go to **Review Before Delete**, without automatic permanent deletion or reclaimed space. Undo refuses changed files/occupied originals. Preserve state while Undo is needed.

## Limits and feedback

Alpha, not stable or production-ready. Classification can be wrong. [Known issues](../../KNOWN_ISSUES.md) covers budgets and independent-PC/physical-drive acceptance gaps. Read [Safety](../SAFETY.md) and [Privacy](../PRIVACY.md).

Use bug forms with versions, synthetic steps and Undo outcome. Never attach private documents/databases, sensitive names or unsanitized reports/logs. Vulnerabilities follow [SECURITY](../../SECURITY.md).
